# ABAP Workbench

ABAP 문법과 코드 예제, 템플릿을 정리한 개인 학습용 웹사이트입니다.

[사이트 바로가기](https://abap-workbench-dohyun.doyhun.chatgpt.site/)

## 주요 기능

- ALV · READ · LOOP · 신문법 예제
- 코드 검색, 구문 강조, FORM 바로가기
- 필드 카탈로그 등 코드 생성기
- 코드 복사와 HTML · ZIP 저장
- 즐겨찾기, 개인 템플릿, JSON 백업

## 실행

```bash
python -m http.server 4175 --directory dist
```

브라우저에서 `http://localhost:4175`를 엽니다.
Windows에서는 `python` 대신 `py`를 사용해도 됩니다.
